Throughout this assignment, I learned how to collect, organize, and analyze data from websites using different web scraping techniques. I became more familiar with HTML elements and how CSS selectors, including class selectors, id selectors, and sibling selectors, can be used to locate specific information on a webpage. I also learned how to use `inner_text` to extract text and attributes to retrieve additional information from HTML elements. One concept I found especially useful was understanding how a headless browser works and why it is sometimes necessary to wait for JavaScript to load before collecting data. I also learned how crawling and pagination allow programs to navigate multiple pages and gather larger amounts of information.

One area I found challenging was extracting and organizing data into a useful format. Using `read_html` and `melt` helped me understand how to collect tables from webpages and reshape data for analysis. However, I still need more practice recognizing how data is structured and determining the best way to organize it. I also learned about fuzzy matching and normalization, which help identify and compare similar values even when the information is not an exact match. Understanding how to choose an appropriate threshold was important because it affects which matches are considered reliable. Another concept I found challenging was using a human in the loop to review uncertain matches and prevent incorrect results. I also learned how a merge indicator can identify which records matched when combining datasets, making it easier to perform a gap analysis and identify missing information.

Moving forward, I want to practice writing CSS selectors to target specific HTML elements more accurately, especially when webpages have complicated structures. I also want to experiment with headless browsers, JavaScript waiting, crawling, and pagination so I can become more comfortable collecting data from dynamic websites. For data cleaning, I plan to practice using `read_html`, `melt`, fuzzy matching, and normalization with different datasets. I especially want to understand how changing the matching threshold affects results and how to use a human in the loop to review questionable matches. Finally, I want to practice using merge indicators to identify unmatched records and complete a gap analysis. By working through these specific areas, I can improve my ability to scrape, clean, compare, and analyze data independently.
